Open and run the original Java project in NetBeans

  1. Download and unzip the repository ZIP.
  2. Open the nat-so-naive folder using File → Open Project in NetBeans.
  3. Use JDK 21 (Project Properties → Build → Compile).
  4. Run the main class co.edu.ufps.notsonaive.NotSoNaiveApplication and open http://localhost:8080.
  5. Run tests with Test Project or mvn test.
